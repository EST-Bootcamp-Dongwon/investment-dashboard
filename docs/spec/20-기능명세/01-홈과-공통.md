## 1. F01 · 대시보드 (홈)

| 항목 | 값 |
| --- | --- |
| 등급 · 상태 | **B** · 동작 |
| SPA 라우트 | `home` (`app.js:52`) |
| 화면 코드 | `app/frontend/js/views/home.js` (256줄) |
| 백엔드 | `GET /api/home/market-candle` (`home.js:130`)<br>`POST /api/market/snapshot` (`home.js:204`) |
| 요구 연결 | 없음 (강사님 요구 4화면에 포함되지 않음) |
| 진입 | 기본 진입 화면. `app.js:399` 가 `?view=` 가 없으면 `home` 으로 보냄 |

### 1.1 하는 일

**두 덩어리로 나뉩니다.**

1. **지수 캔들 4종** — KOSPI·KOSDAQ·NASDAQ·S&P 500 을 각각 카드 하나로 보여줍니다.
2. **대표 기업 시세 12종** — 미국 7 + 한국 5 의 현재가와 전일 대비.

### 1.2 입력

사용자가 넣는 값은 **기간 버튼 하나뿐**입니다. 종목은 고정입니다.

| 입력 | 값 | 기본 | 근거 |
| --- | --- | --- | --- |
| 기간 | `1mo` · `3mo` · `6mo` · `1y` | **`3mo`** | `home.js:8,42` |
| 지수 | KOSPI `^KS11` · KOSDAQ `^KQ11` · NASDAQ `^IXIC` · S&P 500 `^GSPC` | 고정 4종 | `home.js:1~6` |
| 미국 대표주 | AAPL · MSFT · GOOGL · AMZN · NVDA · META · TSLA | 고정 7종 | `home.js:12~20` |
| 한국 대표주 | 삼성전자 · SK하이닉스 · LG에너지솔루션 · 삼성바이오로직스 · 현대차 | 고정 5종 | `home.js:22~28` |

기간 버튼은 **카드마다 따로** 동작합니다 (`home.js:107` 이 `Map` 으로 카드별 기간을 들고 있음).

### 1.3 처리

**지수 캔들 — 서버.** `home_market_candle()` (`main.py:2125~2178`) 이 yfinance 일봉을
받아 `{date,o,h,l,c,v}` 배열로 바꿉니다. **실패하면 난수로 캔들을 만들어 200 으로 돌려줍니다**
(`main.py:2153~2178`). 이때 `is_simulated: true` 가 붙습니다.

```python
# app/backend/main.py:2155~2162 — 표준 난수가 아니라 선형합동생성기(LCG)
rng_state = config["seed"]                       # main.py:2118~2121 시장별 고정 시드
rng_state = (rng_state * 1664525 + 1013904223) % 2**32
```

시드가 시장별로 고정(`kospi` 42 · `kosdaq` 73 · `nasdaq` 109 · `sp500` 151)이라
**폴백 캔들은 매번 똑같은 모양**입니다. 봉 개수는 `int(days * 0.72)` 로,
`PERIOD_DAYS`(`main.py:2116`)의 달력일에 거래일 비율 0.72 를 곱한 근사치입니다.

**지수 캔들 — 화면.** MA20 은 **브라우저가 계산**합니다. 앞 19봉은 `null` 이라 선이 그려지지
않습니다 (`home.js:149~152`). 캔들·MA20·거래량을 ApexCharts 한 장에 겹칩니다
(`home.js:158~173`).

**대표 기업 시세.** 12종목을 `POST /api/market/snapshot` **한 번**으로 받습니다
(`home.js:203~209`). 서버는 종목마다 `yf.Ticker(...).fast_info` 를 먼저 쓰고
(`main.py:1260~1266`), 실패하면 최근 5일 일봉의 마지막 종가로 내려앉으며
(`main.py:1278~1291`), 그것도 실패하면 그 종목만 `status: "error"` 로 표시합니다
(`main.py:1293~1294`). **한 종목이 실패해도 나머지는 정상 출력됩니다.**

### 1.4 출력

| 영역 | 표시 | 근거 |
| --- | --- | --- |
| 카드 머리 | 지수명 · 티커 · 마지막 종가 · 전일 대비 % | `home.js:140~142` |
| 차트 | 일봉 캔들 + MA20 + 거래량 막대 | `home.js:158~173` |
| 카드 발 | `일봉 · MA20 · 거래량` + **데이터 출처** | `home.js:50~51,143` |
| 종목 행 | 이름 · 티커 · 현재가 · 전일 대비 % | `home.js:230~232` |
| 조회 시각 | `조회 HH:MM` (KST 변환) | `home.js:235~238` |

**상승이 빨강, 하락이 파랑입니다** (`home.js:9~10`, `#e11d48` / `#2563eb`).
한국 관행이고 미국식과 반대이므로 `50-UI/디자인-토큰.md` 에 고정해야 합니다.

**시각은 KST 로 맞게 나옵니다.** 서버가 `pd.Timestamp.utcnow().isoformat()` 을 주는데
pandas 2.3.3 에서 이 값은 `+00:00` 오프셋을 포함하고
(실측 2026-08-10, `docker run --rm --entrypoint python investment-portfolio-site-backend:latest`),
`new Date(...)` → `toLocaleTimeString('ko-KR')` 이 브라우저 지역시로 환산합니다.

## 2. F02 · 서버 리소스 모니터

| 항목 | 값 |
| --- | --- |
| 등급 · 상태 | **C** · 동작 |
| SPA 라우트 | `server-resources` (`app.js:53`) |
| 화면 코드 | `app/frontend/js/views/serverResources.js` (174줄) |
| 백엔드 | `GET /api/system/resources` (`serverResources.js:136`)<br>`GET /api/health` (`app.js:382`)<br>`POST /api/visitors/heartbeat` (`app.js:375`) |
| 요구 연결 | 없음 |

### 2.1 하는 일

호스트의 **CPU · 메모리 · 루트 디스크(/) 사용률**을 5초마다 갱신해 도넛 3개와
시계열 1개로 보여줍니다. 제품 기능이 아니라 **운영 확인용**입니다.

### 2.2 처리

| 지표 | 계산 | 근거 |
| --- | --- | --- |
| CPU | `/proc/stat` 을 **0.1초 간격으로 두 번** 읽어 그 구간의 idle 비율을 뺀다 | `main.py:198~203` |
| 메모리 | `/proc/meminfo` 의 `MemTotal − MemAvailable` | `main.py:176~186` |
| 디스크 | `os.statvfs("/")` | `main.py:206~209` |

CPU 는 누적 틱이라 **한 시점만 읽어서는 사용률을 알 수 없습니다.** 그래서
`time.sleep(0.1)` 로 두 번 샘플링합니다 (`main.py:199`). 즉 **이 엔드포인트는
요청마다 최소 0.1초가 걸립니다.**

`/proc` 이 없는 환경을 대비해 `os.sysconf` 폴백이 있습니다 (`main.py:187~191`).
전부 실패하면 **503** 입니다 (`main.py:224~225`).

### 2.3 갱신 주기

| 항목 | 주기 | 근거 |
| --- | --- | --- |
| 리소스 폴링 | **5초** | `serverResources.js:9` |
| 시계열 보관 | 최근 **60개** (= 5분) | `serverResources.js:8` |
| 헬스체크 | 30초 (전역, 화면 무관) | `app.js:381~382` |
| 방문자 하트비트 | 30초 + 탭이 다시 보일 때 | `app.js:386~389` |

화면을 벗어나면 `window._viewCleanup` 이 타이머를 끕니다 (`serverResources.js:167~168`).

### 2.4 현재 접속자 수 — 통계가 아니라 재실 표시

`POST /api/visitors/heartbeat` 는 **인메모리 dict** 에 `{visitor_id: 마지막시각}` 을 넣고
90초가 지난 항목을 지웁니다 (`main.py:56,240~251`). 방문 이력을 남기지 않는다는 뜻이
주석에 명시돼 있습니다 (`main.py:234~239`).

`visitor_id` 는 브라우저가 만들어 `localStorage` 에 저장합니다 (`app.js:354~367`).

| 경로 | 길이 | 근거 |
| --- | --- | --- |
| `crypto.randomUUID().replaceAll('-','')` | **32자 고정** | `app.js:356` |
| 폴백 `Date.now().toString(36) + Math.random().toString(36).slice(2) × 2` | 보통 **30자 안팎** | `app.js:357` |

> **[CN-030](../00-index/변경이력.md#cn-030) 의 "(확인 필요)" 를 좁힙니다.**
> 폴백 경로의 이론적 하한은 `Math.random()` 이 `0` 을 반환하면 `slice(2)` 가 빈 문자열이 되어
> **8자**까지 내려갈 수 있고, 그 경우 `min_length=16`(`main.py:229`)에 걸려 **422** 가 됩니다.
> 확률은 무시할 만하지만 **하한이 보장되지 않는 것은 사실**이므로, 서버 이관 시
> 길이를 프런트에서 먼저 보정합니다.

| # | 문제 | 근거 | 처리 |

| 1 | **서버리스에서 의미가 깨진다** | `_active_visitors` 가 프로세스 메모리 (`main.py:57`) | 인스턴스마다 다른 수를 보여줌 → [CN-037](../00-index/변경이력.md#cn-037) |

## 3. 두 기능의 공통 관심사

### 3.1 전역 폴링이 3개 돌고 있습니다

화면과 무관하게 `app.js` 가 항상 돌리는 타이머입니다.

| 대상 | 주기 | 근거 |
| --- | --- | --- |
| `/api/health` | 30초 | `app.js:381~382` |
| 상단바 시세 (`^KS11`·`^IXIC`·`KRW=X`) | 30초 | `app.js:48,383~384` |
| 방문자 하트비트 | 30초 | `app.js:46,385~386` |

**상단바 시세가 `POST /api/market/snapshot` 을 30초마다 부릅니다.** 홈 화면에 있으면
같은 엔드포인트를 두 곳에서 쓰는 셈이고, Yahoo 요청 제한(429)에 기여합니다.
→ [CN-037](../00-index/변경이력.md#cn-037) 의 캐시 정책이 여기에도 적용됩니다.

### 3.2 라우터는 해시가 아니라 쿼리스트링입니다

`?view=home` 형태이고, 정적 페이지(`pages/*.html`)에서 돌아올 때를 위해
진입 시 한 번 해석합니다 (`app.js:397~399`). 뒤로가기 동작은 **(확인 필요)** 입니다 —
`history.pushState` 호출 여부를 이 세션에서 확인하지 않았습니다.
