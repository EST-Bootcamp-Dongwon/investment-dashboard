## 2. 폐기 근거

### 2.1 용량 — 이것이 결정적입니다

| 항목 | 값 | 측정 |
| --- | --- | --- |
| 백엔드 이미지 | **2.49 GB** | `docker images` (2026-08-07) |
| 그중 `torch`·`diffusers`·`opencv` 기여 | 대부분 | `requirements.txt:18~25` |
| **Vercel Python 함수 상한** | **500 MB** (압축 해제) | [Functions Limits](https://vercel.com/docs/functions/limitations) (2026-08-09) |

**[D-06](../00-index/마스터인덱스.md#2-지금-확정된-설계-결정)(Vercel 단일 배포)을 정한 순간
이 셋은 선택지가 아니게 됐습니다.** `torch` 하나만으로도 500 MB 에 근접합니다.

> [CN-019](../00-index/변경이력.md#cn-019) 가 적은 대로 **"X01~X05 폐기가 배포의 전제"** 입니다.
> 잔여 의존성이 실제로 500 MB 안에 들어가는지는 **첫 배포에서 실측** — 지금은 **(확인 필요)**.

### 2.2 포트폴리오 분석과 무관

다섯 기능 모두 강사님 요구 R-01~R-08 중 어느 것에도 대응하지 않습니다.
X04(이미지 생성)와 X05(원 애니메이션)는 투자와 아무 관계가 없습니다.

### 2.3 X01~X03 은 합성 데이터로 학습합니다

| 기능 | 데이터 | 근거 |
| --- | --- | --- |
| X01 | 합성 시계열 `n_samples` 500~10,000 | `ml.py:120~124` |
| X02 | 시뮬레이션 일수 500~5,000 | `ml.py:126~131` |
| X03 | 인코더 창 20~80 | `ml.py:133~138` |

**실제 주가를 학습하지 않으므로 예측 성능에 의미가 없습니다.**
"딥러닝으로 주가를 예측한다"는 인상만 남고 근거는 없습니다 — R-07 관점에서도 좋지 않습니다.

### 2.4 X05 는 이미 한 번 고쳐진 이력이 있습니다

```
# requirements.txt:22~24
# 원본은 opencv-python(GUI 빌드)이었는데, python:3.12-slim 에는 libxcb.so.1 이 없어
# `import cv2` 자체가 ImportError 로 실패했다(=/api/cv/circle-animation 이 항상 500).
```

**환경 문제를 한 번 해결하고 유지해 온 코드**입니다. 그럼에도 제품 가치가 없어
지웁니다. 이 이력을 남기는 이유는, 같은 문제로 다시 시간을 쓰지 않기 위해서입니다.

## 6. 실행 순서

지우는 순서가 중요합니다. 잘못하면 화면이 깨집니다.

```
1. app.js 의 import 5줄·routes 5항목·_practiceViews 2항목 제거   ← 진입을 먼저 막는다
2. view 파일 5개 삭제 + sentiment.js 삭제       ← cloudAiResources.js 는 남긴다 (3.1절)
3. api.js 바인딩 5개 제거
4. ml.py 라우트 6개 + 요청 모델 제거
5. openapi_docs.py 정리
6. requirements.txt 3줄 제거
7. 이미지 재빌드 → 용량 실측                    ← 500MB 이내인지 확인
8. 전 화면 진입 테스트                          ← 남은 화면이 깨지지 않았는지
```

> **`cloudResourceCard()` 호출부는 따로 지울 것이 없습니다.** 이 함수를 쓰는 폐기 대상
> 3개(`cnnTimeseries`·`lstm`·`transformer`)가 파일째 사라지면서 호출도 함께 사라집니다.
> 남는 9개 뷰는 그대로 씁니다.

**8번에서 500 MB 를 넘으면** 다음 후보는 `matplotlib` 입니다 — base64 차트 16곳이
의존합니다 ([마스터인덱스 4.1](../00-index/마스터인덱스.md#4-코드-실측치-2026-08-07-기준)).
그 경우는 별도 판단이 필요하므로 **지금 결정하지 않습니다.**
