## 0. 이 문서의 성격

토큰은 **"어떤 색이 예쁜가" 가 아니라 "같은 뜻에는 같은 값을 쓴다" 는 약속**입니다.
이 프로젝트에서 그 약속이 지금 얼마나 지켜지고 있는지부터 실측합니다.

## 1. 현황 실측 (2026-08-10)

### 1.1 토큰은 있는데 거의 쓰이지 않습니다

```css
/* app/frontend/styles.css:1~29 */
:root {
  --bg: #ffffff;  --surface: #ffffff;  --surface-soft: #f8f9fa;  --surface-hover: #f0f7ff;
  --text: #1a1a1a;  --text-muted: #555555;  --text-subtle: #8a8a8a;
  --border: #e0e0e0;  --border-strong: #bdbdbd;
  --primary: #0078d4;  --primary-dark: #004578;  --primary-light: #eff6ff;  --accent: #2b88d8;
  --green: #059669;  --green-bg: #ecfdf5;
  --red: #dc2626;    --red-bg: #fef2f2;
  --yellow: #eab308; --yellow-bg: #fefce8;
  --sidebar-w: 268px;  --topbar-h: 56px;
  --radius: 10px;  --radius-sm: 6px;
  --shadow-sm: …;  --shadow: …;  --shadow-lg: …;
  font-family: "Pretendard", …;
}
```

| 항목 | 값 | 측정 |
| --- | ---: | --- |
| `:root` 변수 정의 | **26** | `sed -n '/^:root {/,/^}/p' styles.css \| grep -c "^\s*--"` |
| ─ 색 | 17 | 위 목록 |
| ─ 치수·그림자 | 9 | |
| **CSS 안 고유 hex 색** | **132** | `grep -oE "#[0-9a-fA-F]{6}" styles.css \| sort -u \| wc -l` |
| **JS 안 hex 색 등장** | **1,563** | `grep -roE "#[0-9a-fA-F]{3,8}" app/frontend/js/ \| wc -l` |
| ─ 그중 고유 색 | **115** | |
| **JS 안 `var(--…)` 사용** | **58** | `grep -ro "var(--[a-z-]*)" app/frontend/js/ \| wc -l` |
| **JS 안 인라인 `style=`** | **1,126** | `grep -ro 'style="' app/frontend/js/ \| wc -l` |

**JS 에서 색을 지정하는 1,621회 중 토큰을 쓴 것은 58회(3.6 %)입니다.**
토큰 시스템이 존재하지만 **사실상 우회되고 있습니다.**

### 1.2 척도가 없습니다

| 축 | 고유값 개수 | 측정 |
| --- | ---: | --- |
| `font-size` | **62** | `grep -oE "font-size: ?[0-9.]+(rem\|px\|em)" \| sort -u \| wc -l` |
| `border-radius` | **17** | 〃 |
| `padding` (단일값) | **28** | 〃 |
| `gap` | **19** | 〃 |
| 미디어쿼리 브레이크포인트 | **12** | `grep -oE "\((max\|min)-width: [0-9]+px\)" \| sort -u` |

`font-size` 62종은 척도가 아니라 **그때그때 정한 값**입니다.
`.72rem`·`.74rem`·`.75rem`·`.76rem` 이 모두 따로 쓰입니다.

### 1.3 다크 모드는 없습니다 — 다크 화면은 있습니다

```
$ grep -cE "prefers-color-scheme|data-theme|\.dark" app/frontend/styles.css   # 2026-08-10
0
```

**다크 모드 지원은 0건**입니다. 그런데 **F23(DART 재무 분석)은 화면 전체가 다크**입니다.

```html
<!-- dartFinancialAnalysis.js:175 -->  <div style="background:#1e293b; border:1px solid #334155; …">
<!-- dartFinancialAnalysis.js:255 -->  <p style="… color:#cbd5e1; …">
<!-- dartFinancialAnalysis.js:168 -->  green: { bg:'#052e16', border:'#16a34a', color:'#4ade80' }
```

라이트 앱 안에 **다크 화면 하나가 인라인 스타일로 박혀 있습니다.**
[화면-상세 7.4절](화면-상세.md#74-f23--f19-의-다크-ui-혼입) 참고.

## 4. 색 토큰 — 의미

여기가 이 프로젝트에서 **가장 자주 틀리는 자리**입니다.
같은 빨강이 "손실"·"오류"·"상승" 세 가지 뜻으로 쓰이고 있습니다.

### 4.1 등락 색 — 한국식

```javascript
// app/frontend/js/views/home.js:9~10
const UPWARD_COLOR   = '#e11d48';   // 빨강 = 상승
const DOWNWARD_COLOR = '#2563eb';   // 파랑 = 하락
```

**한국 증시 관행(상승=빨강 / 하락=파랑)을 따릅니다.** 서구권(상승=초록 / 하락=빨강)과
반대이므로 **토큰으로 고정하고 이름에 뜻을 박습니다.**

| 토큰 | 값 | 뜻 |
| --- | --- | --- |
| `--rise` | `#e11d48` | **상승 · 플러스** |
| `--rise-bg` | `#fff1f2` | 상승 배경 |
| `--fall` | `#2563eb` | **하락 · 마이너스** |
| `--fall-bg` | `#eff6ff` | 하락 배경 |

**현행 사용처 실측** — 이미 이 값이 쓰이고 있으나 **매번 하드코딩**입니다.

```css
/* styles.css:706~707 */  .home-market-price-row em.is-up   { background:#fff1f2; color:#e11d48; }
                          .home-market-price-row em.is-down { background:#eff6ff; color:#2563eb; }
/* styles.css:744~745 */  .home-quote-value em.is-up   { color:#e11d48; }
                          .home-quote-value em.is-down { color:#2563eb; }
/* styles.css:842   */    .world-market-quote.is-up { color:#e11d48; } … .is-down { color:#2563eb; }
/* styles.css:790~791 */  .volume-cloud-stage-head i.is-up { color:#fb5165; } … .is-down { color:#4487ee; }
/* styles.css:805~806 */  .volume-cloud-tooltip em.is-up { color:#fb7185; } … .is-down { color:#60a5fa; }
```

> ⚠ **F10(거래량 클라우드)만 다른 값을 씁니다** — `#fb5165`/`#4487ee` 와
> `#fb7185`/`#60a5fa`. 같은 뜻인데 화면마다 색이 다릅니다.
> **토큰으로 통일합니다.** 어두운 배경 위라 대비가 필요하면
> `--rise-on-dark` / `--fall-on-dark` 를 따로 둡니다.

**그리고 `.up`/`.dn` 이 초록/빨강입니다.**

```css
/* styles.css:147~148 */
.up { color: var(--green); }   /* #059669 초록 */
.dn { color: var(--red);   }   /* #dc2626 빨강 */
```

이 클래스는 **상단 티커**가 씁니다(`app.js:337`). 즉 **같은 화면 안에서
상단 티커는 서구식(초록/빨강), 홈 카드는 한국식(빨강/파랑)** 입니다.

**v2.0**: `.up`/`.dn` 을 `--rise`/`--fall` 로 바꿉니다. **한 화면에 두 관행이 섞여 있는
것은 명백한 결함입니다** — 상단 티커가 빨강이면 사용자는 "떨어졌다" 로 읽습니다.

### 4.2 상태 색

등락과 **분리**합니다. 등락의 빨강(`--rise`)과 오류의 빨강(`--danger`)은 다른 뜻입니다.

| 토큰 | 값 | 뜻 | 현행 |
| --- | --- | --- | --- |
| `--ok` | `#059669` | 정상·성공·양호 | `--green` |
| `--ok-bg` | `#ecfdf5` | | `--green-bg` |
| `--warn` | `#eab308` | 주의·예시 데이터·확인 필요 | `--yellow` |
| `--warn-bg` | `#fefce8` | | `--yellow-bg` |
| `--warn-border` | `#facc15` | | 신설 |
| `--warn-text` | `#854d0e` | 배너 본문 (대비 확보) | 신설 |
| `--danger` | `#dc2626` | 오류·실패 | `--red` |
| `--danger-bg` | `#fef2f2` | | `--red-bg` |
| `--muted-badge` | `#8a8a8a` | 중립 배지 | `--text-subtle` 재사용 |

**적용 지점.**

| 쓰임 | 토큰 | 근거 |
| --- | --- | --- |
| `is_simulated` 배너 | `--warn-*` | [화면-상세 2.2절](화면-상세.md#22-공통-배너-컴포넌트-사양) |
| 백엔드 오프라인 표시 | `--danger` | `app.js:284` 가 `#ef4444` 하드코딩 |
| 백엔드 연결됨 | `--ok` | `app.js:281` 이 `#22c55e` 하드코딩 |
| F23 재무 배지 3종 | `--ok` / `--muted-badge` / `--warn` | [화면-상세 4.2절](화면-상세.md#42-v20) |
| `errorState()` | `--danger-*` | [화면-상세 7.3절](화면-상세.md#73-에러-화면) |

> `app.js:281,284` 의 `#22c55e`·`#ef4444` 는 `--green`(`#059669`)·`--red`(`#dc2626`)와
> **다른 값**입니다. 같은 뜻에 두 값이 있습니다.

### 4.3 데이터 출처 배지

[화면목록과-IA 5절](화면목록과-IA.md#5-데이터-출처-배지--신설)에서 신설한 배지 3종입니다.

| 토큰 | 값 | 배지 | 근거 |
| --- | --- | --- | --- |
| `--badge-live` | `#0078d4` (`--primary`) | **실시간** | 신뢰할 수 있는 값 = 주 색 |
| `--badge-live-bg` | `#eff6ff` | | |
| `--badge-static` | `#854d0e` | **학습용 상수** | `--warn` 계열. **주의를 요구하는 값** |
| `--badge-static-bg` | `#fefce8` | | |
| `--badge-input` | `#555555` (`--text-muted`) | **직접 입력** | 중립. 사용자 책임 |

### 4.4 신호등 (F04 전용)

F04 는 상관계수를 신호등으로 보여줍니다(`portfolioCombination.js:85~89`).
**등락 색과 반대 방향이라 반드시 분리해야 합니다** — 신호등의 빨강은 "상승" 이 아니라
"함께 움직여서 분산 효과가 약함" 입니다.

| 토큰 | 값 | 뜻 | 기준 | 서버 근거 |
| --- | --- | --- | --- | --- |
| `--signal-good` | `#059669` | 함께 담기 좋은 편 | 상관계수 **< 0.30** | `main.py:1209` `signal = "green"` |
| `--signal-mid` | `#eab308` | 보통 | **0.30 이상 0.70 미만** | `main.py:1213` `"yellow"` |
| `--signal-weak` | `#dc2626` | 비슷하게 움직이는 편 | **0.70 이상** | `main.py:1217` `"red"` |

**모달이 설명하는 기준과 서버 코드가 일치합니다** —
`correlation` 모달 본문(`portfolioCombination.js:135`)의 "0.30 미만 초록 / 0.30 이상
0.70 미만 노랑 / 0.70 이상 빨강" 이 `main.py:1209~1219` 와 같습니다.
**이 프로젝트에서 화면 설명과 서버 로직이 검증된 몇 안 되는 지점입니다.**

### 5.2 간격 척도 — 신설

**8단계로 고정합니다.** 현행 `gap` 19종·`padding` 28종을 여기에 맞춥니다.

| 토큰 | 값 | 쓰임 |
| --- | ---: | --- |
| `--sp-1` | `4px` | 아이콘과 글자 |
| `--sp-2` | `8px` | 인접 요소 |
| `--sp-3` | `12px` | 카드 내부 행 간격 |
| `--sp-4` | `16px` | 카드 패딩 (기본) |
| `--sp-5` | `20px` | 섹션 내부 |
| `--sp-6` | `24px` | 카드 사이 |
| `--sp-8` | `32px` | 섹션 사이 |
| `--sp-12` | `48px` | 페이지 상하 여백 |

**현행 상위 4개 `gap` 값이 10·16·12·8px** 이므로 `--sp-3`(12) · `--sp-4`(16) ·
`--sp-2`(8) 로 대부분 흡수됩니다. `10px`(26회)은 `12px` 로 올립니다.

### 5.3 브레이크포인트 — 12개 → 4개

| 토큰 | 값 | 대상 | 현행에서 흡수하는 값 |
| --- | ---: | --- | --- |
| `--bp-sm` | `640px` | 휴대폰 | 560 · 640 |
| `--bp-md` | `900px` | 태블릿 세로 | 760 · 860 · 900 |
| `--bp-lg` | `1024px` | **사이드바 접힘 기준** | 960 · 1000 · 1024 · 1025 · 1080 |
| `--bp-xl` | `1440px` | 넓은 화면 | 1440 · 1920 |

**`1024px` 만은 JS 와도 맞춰야 합니다.**

```javascript
// sidebarUI.js:5   const DESKTOP_BREAKPOINT = 1024;
// app.js:212       const MOBILE_BREAKPOINT  = 1024;
```

두 상수가 같은 값을 각자 선언합니다. **한 곳으로 모으고 CSS 와 이름을 맞춥니다.**

> ⚠ CSS 변수는 미디어쿼리 조건에 쓸 수 없습니다. 값은 문서(이 표)를 정본으로 두고,
> `styles.css` 에 `/* --bp-lg */` 주석을 병기합니다.

| 등폭 | **지정 없음** | ❌ 코드 블록·수치 표에 필요 → **신설** |

**`--font-mono` 신설**: `"D2Coding", "Consolas", "Menlo", monospace`.
개념 모달의 코드 블록(`.{p}-code`)과 금액·수치 표에 씁니다.

> ⚠ **CDN 의존.** Pretendard 가 안 뜨면 `Malgun Gothic` 으로 떨어져 자간이 크게 달라집니다.
> 오프라인 심사 가능성이 있으면 `vendor/` 로 옮기는 것을 검토합니다
> ([개념설명-모달-사양 6.2절](개념설명-모달-사양.md#62-결정--되살립니다)의 mermaid 와 같은 판단).

### 11.2 T-05 해소 — `--warn` 을 글자색으로 쓰는 곳

```
$ grep -rn "color:#eab308\|color: *var(--yellow)" app/frontend/          # 실측 2026-08-10
styles.css:1362   .legend-yellow i { color: #eab308; }        ← 아이콘 ✅ 문제없음
styles.css:1388   .chart-why i      { color: #eab308; }        ← 아이콘 ✅ 문제없음
js/views/investmentTree.js:72,87  risk: '중하 <i … style="color:#eab308;">'  ← 아이콘 ✅
```

**4곳 전부 아이콘(`<i>`)이라 본문 글자가 아닙니다.** 지금은 문제가 없습니다.
다만 아이콘도 **비텍스트 대비 3:1** 을 요구받는데 `#eab308` 은 1.92 라 미달입니다.
`--warn` 아이콘 옆에는 **항상 글자 라벨을 함께 둡니다**
(현행 `.legend-yellow` 는 "보통" 텍스트를 갖고 있어 충족).

**신설되는 `is_simulated` 배너는 처음부터 `--warn-text` 로 씁니다** —
[화면-상세 2.2절](화면-상세.md#22-공통-배너-컴포넌트-사양). 배너 문구가 안 읽히면
배너를 만든 의미가 없습니다.
