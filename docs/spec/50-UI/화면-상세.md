## 2. `is_simulated` 배너 — F01 1순위

### 2.1 왜 배너인가

[CN-041](../00-index/변경이력.md#cn-041) 실측 (2026-08-10):

| **F01 홈** | `일봉 · MA20 · 거래량` 옆 **작은 회색 텍스트** (`home.js:143`) | ❌ **약함** |
| F13 거시 실시간 | 경고 박스 (`macroRealtime.js:123~127`) | ✅ |
| F15 KOSPI 제외 | 경고 박스 (`kospiExcluded.js:196~199`) | ✅ |

**셋 다 표시는 하고 있습니다.** [CN-035](../00-index/변경이력.md#cn-035) 의
"사용자가 난수를 실제 시세로 본다" 는 성립하지 않습니다.
문제는 **F01 의 강조 수준**이고, F01 은 **기본 진입 화면**이라 노출이 가장 큽니다.

| 3 | 없는 `view` 가 조용히 홈으로 (`app.js:215`) | **404 화면** 을 내고 사이드바로 안내 |
| 4 | `#breadcrumb` 참조가 죽어 있음 (`app.js:45,234`) | 새 IA 는 2단이므로 **`그룹 › 화면` 빵부스러기를 실제로 넣는다** |

> 1·2 는 `?view=` 형식을 그대로 두므로 정적 페이지의 왕복 링크
> (`sidebar-nav.html:4` `../index.html?view=home`)가 깨지지 않습니다.
> 다만 **실기기 확인이 필요합니다 — (확인 필요)**.
